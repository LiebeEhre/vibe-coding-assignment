# AI 기반 대학생 과제 관리 웹앱

AI-based assignment manager developed with vibe coding process.

## 1. 프로젝트 개요

본 프로젝트는 바이브코딩을 활용하여 대학생의 과제 일정을 관리하는 웹앱을 개발하는 것을 목표로 한다. 사용자는 과제를 등록하고, 마감일을 확인하며, 완료 여부를 관리할 수 있다.

## 2. 개발 목적

본 프로젝트의 목적은 단순히 웹앱을 완성하는 것이 아니라, 요구사항 분석부터 설계, 구현, 테스트, 품질 관리에 이르는 소프트웨어 개발 프로세스 안에서 바이브코딩의 효과와 한계를 분석하는 것이다.

## 3. 사용 기술

- Python
- NiceGUI
- JSON 파일 저장 방식
- GitHub 형상 관리
- ChatGPT 기반 바이브코딩

## 4. 주요 기능

- 과제 추가
- 과제 목록 조회
- 과제 완료 처리
- 과제 삭제
- 마감일 관리
- 전체/완료/미완료 필터링
- 입력값 검증

## 5. 저장 방식

본 프로젝트는 별도의 데이터베이스를 사용하지 않고 tasks.json 파일을 사용하여 과제 정보를 저장한다. 과제를 추가하거나 완료 처리, 삭제할 때 변경된 과제 정보가 JSON 파일에 반영되도록 구성하였다.

## 6. 실행 방법

프로젝트 폴더에서 다음 명령어를 입력하여 웹앱을 실행한다.

bash python3 main.py 

NiceGUI 기본 포트에서 충돌이 발생할 경우, 코드의 실행 부분에서 다음과 같이 다른 포트를 지정하여 실행할 수 있다.

python ui.run(port=8090) 

실행 후 브라우저에서 다음 주소로 접속한다.

text http://127.0.0.1:8090 

## 7. 개발 프로세스

본 프로젝트는 다음과 같은 순서로 진행하였다.

1. 요구사항 분석
2. 화면 및 데이터 구조 설계
3. AI 기반 코드 생성
4. 실행 및 오류 수정
5. UI 개선
6. 기능 테스트
7. 품질 관리
8. 결과 정리

### 7.1 요구사항 분석

대학생이 과제를 관리할 때 필요한 기본 기능을 중심으로 요구사항을 정리하였다. 과제 제목, 설명, 마감일, 완료 여부를 관리할 수 있도록 기능 범위를 설정하였다.

### 7.2 화면 및 데이터 구조 설계

사용자가 과제를 입력하는 영역과 등록된 과제를 확인하는 목록 영역을 분리하여 화면을 구성하였다. 과제 데이터는 제목, 설명, 마감일, 완료 상태를 포함하도록 설계하였다.

### 7.3 AI 기반 코드 생성

ChatGPT를 활용하여 NiceGUI 기반의 초기 코드를 생성하였다. 이후 실행 과정에서 발생한 오류를 수정하고, 필요한 기능을 단계적으로 추가하였다.

### 7.4 UI 개선

전체, 완료, 미완료 필터 버튼을 눌렀을 때 현재 선택된 필터를 사용자가 쉽게 인식할 수 있도록 버튼 색상과 테두리 스타일을 수정하였다. 선택된 버튼만 강조되도록 구성하여 화면의 가독성을 높였다.

### 7.5 테스트 및 품질 관리

과제 추가, 완료 처리, 삭제, 필터링, 입력값 검증, 포트 변경 실행 기능을 테스트하였다. 각 기능의 정상 동작 여부는 실행 화면 캡처와 기능별 테스트 결과 표를 통해 확인하였다.

## 8. 기능별 테스트 결과

| 테스트 항목 | 테스트 내용 | 예상 결과 | 실제 결과 |
|---|---|---|---|
| 빈 목록 표시 | 등록된 과제가 없는 상태에서 과제 목록을 확인한다. | 표시할 과제가 없다는 안내 문구가 출력된다. | 정상 동작 |
| 과제 추가 | 제목, 설명, 마감일을 입력한 뒤 과제 추가 버튼을 클릭한다. | 입력한 과제가 목록에 추가된다. | 정상 동작 |
| 날짜 선택 | 달력 UI에서 마감일을 선택한다. | 선택한 날짜가 마감일로 반영된다. | 정상 동작 |
| 완료 처리 | 미완료 상태의 과제에서 완료 버튼을 클릭한다. | 과제 상태가 완료로 변경된다. | 정상 동작 |
| 전체 필터 | 전체 버튼을 클릭한다. | 완료 및 미완료 과제가 모두 표시된다. | 정상 동작 |
| 미완료 필터 | 미완료 버튼을 클릭한다. | 미완료 상태의 과제만 표시된다. | 정상 동작 |
| 완료 필터 | 완료 버튼을 클릭한다. | 완료 상태의 과제만 표시된다. | 정상 동작 |
| 입력값 검증 | 필수 입력값을 비운 상태에서 과제 추가를 시도한다. | 과제가 추가되지 않고 검증 메시지가 표시된다. | 정상 동작 |
| 삭제 기능 | 과제의 삭제 버튼을 클릭한다. | 해당 과제가 목록에서 제거된다. | 정상 동작 |
| 포트 변경 실행 | 기본 포트 충돌 시 8090 포트로 실행한다. | 지정한 포트에서 앱이 실행된다. | 정상 동작 |

## 10. 프로젝트 결과

본 프로젝트를 통해 바이브코딩을 활용하여 과제 관리 웹앱을 구현하였다. 과제 추가, 목록 조회, 완료 처리, 삭제, 마감일 관리, 필터링 기능을 포함하여 기본적인 과제 관리 흐름을 구성하였다.

개발 과정에서는 AI가 초기 코드 작성과 오류 수정 방향을 제시하는 데 도움이 되었으나, 실행 결과를 확인하고 요구사항에 맞게 수정하는 과정은 개발자가 직접 판단해야 했다. 특히 필터 버튼의 선택 상태 표시, 입력값 검증, 포트 충돌 해결과 같은 부분은 실제 실행 화면을 확인하면서 반복적으로 개선하였다.

따라서 바이브코딩은 개발 속도를 높이고 아이디어를 빠르게 구현하는 데 효과적이지만, 최종 품질을 확보하기 위해서는 기능 테스트와 사용자 관점의 UI 점검이 함께 필요하다는 점을 확인하였다.
